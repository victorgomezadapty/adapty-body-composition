# Roadmap

## Version 0.1 MVP

- FastAPI application
- SQLite persistence with SQLModel
- Client, record, goal, and plan CRUD
- Progress summaries
- Coach and client reports
- Synthetic seed data
- Streamlit dashboard
- Tests and GitHub Actions

## Version 0.2

- Benchmark engine by gender, age group, goal, and location.
- More dashboard filters and cohort comparisons.
- Exportable coach reports.

## Version 0.3

- AI coach assistant for clearer educational explanations.
- Prompt and safety templates.
- Human review workflow.

## Version 0.4

- Nutrition guidance engine with educational calorie and macro ranges.
- Plan adherence tracking.
- Synthetic longitudinal dataset generation.

## Version 0.5

- Simple prediction models using synthetic records.
- Progress risk flags.
- Model evaluation documentation.

## Version 1.0

- Authentication and role-based access.
- Cloud deployment.
- InBody import tooling.
- Manager reports.
- Production-grade privacy and audit controls.
